# Security Policy

## Supported Versions

Only the latest release of `go-flow` receives active security updates and patches.

| Version | Supported          |
| :------ | :----------------- |
| >=0.6.0 | :white_check_mark: |
| < 0.6.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in `go-flow`, please do not open a public GitHub issue.

Instead, please report vulnerabilities by:

1. Submitting a private security advisory through GitHub:
   Navigate to the **Security** tab of the repository and click **Report a vulnerability**.
2. Or contacting the maintainers directly via email.

Please include the following details in your report:

- Type of issue (e.g., race condition, denial of service, memory exhaustion).
- Step-by-step instructions or reproducible Go code snippet.
- Impact on applications utilizing the library.

### Vulnerability Response Process

- We will acknowledge receipt of your vulnerability report within 48 hours.
- A fix or mitigation will be developed, reviewed, and published in a security patch release.
- Public disclosure will take place after the patch has been released.
